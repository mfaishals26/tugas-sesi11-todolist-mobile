# Tugas Sesi 11 – Todo List Mobile

Aplikasi **Todo List Mobile** ini dikembangkan sebagai bagian dari **Tugas Pemrograman Mobile Sesi 11**.  
Aplikasi bertujuan untuk membantu pengguna dalam mencatat, menampilkan, dan mengelola daftar tugas secara sederhana melalui perangkat mobile.

## 📱 Deskripsi Aplikasi
Aplikasi ini dibuat menggunakan **React Native dengan Expo** dan menerapkan struktur komponen yang modular.  
Pengguna dapat menambahkan tugas baru, melihat daftar tugas, serta mengelola data todo secara terstruktur.

## ⚙️ Teknologi yang Digunakan
- React Native
- Expo
- TypeScript
- Node.js & NPM

## 📂 Struktur Project
- `app/` : Berisi halaman utama dan routing aplikasi
- `components/` : Komponen UI Todo List
- `services/` : Logika pengelolaan data todo
- `assets/` : Gambar dan ikon aplikasi
